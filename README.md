# RENOVA CLEAN

Website institucional da **RENOVA CLEAN**, desenvolvido para apresentar os serviços de limpeza e facilitar o contacto de potenciais clientes com a empresa.

> **Estado do projeto:** em desenvolvimento/revisão. Antes da publicação, confirmar os contactos, preços, informações comerciais e imagens apresentados no site.

## Objetivo

O site tem como objetivo apresentar a RENOVA CLEAN de forma profissional, explicar os serviços disponíveis e orientar os visitantes para solicitar informações ou entrar em contacto, incluindo através do WhatsApp.

## Conteúdo do site

A página inicial reúne secções de apresentação e conversão, incluindo:

- Apresentação da empresa e chamada para ação;
- Serviços disponibilizados;
- Resultados e comparação visual de antes/depois;
- Etapas do processo de atendimento;
- Preços ou referências de preços;
- Perguntas frequentes;
- Contacto e ligação para o WhatsApp.

A presença e o conteúdo de cada secção devem ser confirmados no código à medida que o projeto evolui.

## Tecnologias

Com base nos ficheiros atuais do projeto:

- **HTML5** — estrutura e conteúdo da página;
- **CSS3** — identidade visual, layout e adaptação a diferentes ecrãs;
- **JavaScript** — interações da interface, como o menu móvel, animações de entrada e controlo do comparador antes/depois.

O projeto é construído com tecnologias web do lado do cliente. Este README não pressupõe a existência de backend, base de dados ou sistema de autenticação.

## Funcionalidades implementadas no código

- Navegação entre secções da página;
- Menu adaptado a dispositivos móveis;
- Animações de revelação de elementos durante a navegação;
- Comparador visual de antes/depois;
- Ligações de contacto, incluindo WhatsApp.

Estas funcionalidades devem ser testadas no navegador após cada alteração. A presença no código não substitui a verificação prática de que tudo funciona corretamente.

## Identidade visual

O site utiliza uma identidade visual baseada sobretudo em tons de azul-escuro e azul, com verde como cor de destaque. O objetivo é transmitir limpeza, confiança e profissionalismo.

## Como executar localmente

1. Descarrega ou clona o repositório para o computador.
2. Mantém `index.html`, `css/style.css`, `js/script.js` e os recursos visuais nos caminhos indicados acima.
3. Abre `index.html` num navegador. Para uma experiência de desenvolvimento mais cómoda, podes usar a extensão **Live Server** no Visual Studio Code.
4. Testa as secções e interações, tanto em ecrã grande como em ecrã pequeno.

## Manutenção

- Mantém o HTML, CSS e JavaScript organizados nos respetivos ficheiros.
- Atualiza este README quando forem adicionadas ou removidas funcionalidades.
- Não publiques contactos, preços, fotografias ou testemunhos sem confirmar que são os dados oficiais e que existe autorização para os utilizar.
- Antes de uma nova versão, testa os links e as interações principais.
